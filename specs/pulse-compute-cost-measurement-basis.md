# 全过程协作计量：试验与判定依据

适用 WI：wi_20261008_550。与 [协作计量契约](pulse-compute-cost-collaboration-contract.md) 一起构成 model 节点的工程输入，不是产品验收报告。

以下门槛由 Pulse 按大鸟的设计委托在试验前设定；它们是工程判断，不是实测结果、统计置信度或人类已经确认的时长。原 A1–A10 不变。

## 1. 要支持的判断

- 看清每个阶段产生了什么、相对目标有何变化，以及人的主要投入花在哪里。
- 对同目标、同质量、同观察范围的工作，识别至少 5 分钟量级的可避免负担差异。小于该量级或估计区间重叠时，不给出“节省了多少”的确定排名。
- 不用于按秒计费、人员绩效评分或自动删减人类共创/验收。日常没有人类费率与收益基线时，不输出货币 ROI。

阶段由实际目标、产出、重要反馈和交接界定，不按每次工具调用分段。阶段窗口用发生时间的半开区间表示，默认 UTC+8；报告另固定知识截止（水位），迟到关联不改变旧截止结果。

## 2. 人类投入的估计单位与方法

### 2.1 一个参与片段

以一次可辨认的人类参与为单位，绑定人类输入引用及所针对的材料/任务；阅读、思考、输入可能共同构成一个片段，不逐句计件。多次消息属于同一连续参与时保存成员集合，一条消息也可关联多个用途，但时间只计一次。仅知道回复间隔不证明连续参与；不能因相邻时间近而合并。

客观记录与解释分列：

- `activity_refs`：可核对的提交/反馈和实际材料引用；投递成功不证明阅读。
- `purpose`：共创、阅读判断、验收、协调、纠错/恢复的一个主用途，可附次用途；分类为 Agent 判断，保留依据与不确定项。
- `active_seconds`：实测区间（若有）、人类自报区间（若有）、Agent 估计区间分别保存，三者不相加。
- `unobserved_scope`：线下查资料、讨论、未阅读材料、分心或并行工作等可能缺项。没有可用上界时，不生成整个阶段的完整时间上界。

没有证据说明读了哪些材料时，可给“已知互动部分”的估计，不把整篇输出按阅读速度计入。没有任何可解释时间依据则 abstain（不估计），活动本身仍计数；此类样本不会从验证分母消失。

### 2.2 首版估计器

在已有阶段总结中，由当前 Agent 一并输出参与片段的有限区间 `[L,U]`（秒）、依据和未观测范围，不单开模型调用、不要求用户逐条确认。区间只能表达有依据的参与部分，不能用消息间隔、旧 HAU 权重或统一“每条消息 N 秒”生成。

保留估计规则版本、实际模型配置引用与片段成员集合。规则包括：只使用该片段已经可见的事实；不看参考答案；说明阅读、判断、输入及纠错是否已含在同一时间；不得以将来验收结果倒推当时投入。

校准只允许一个全局尺度参数，不拟合多类权重：

1. 四个预定校准片段先保存初估，后取得有限核对的参考区间 `[a,b]`。
2. 对非零、可比片段，以 `r=(a+b)/2`、`m=(L+U)/2` 计算 `r/m`；尺度 `k` 为这些比值的中位数（偶数取中间两项均值）。
3. 四个片段不足以得到至少三个有效比值，或 `k` 不在 `[0.5,2]`，停止该估计器，不靠更大修正系数把错误设计校准成“通过”。明确零投入的片段单独检查，不以除零丢弃。
4. 后续冻结规则、配置和 `k`；输出 `[kL,kU]`。参数只是可审计校准，不叫实测或总体置信区间。模型/规则发生实质变化，旧验证不转授给新版本。

报告按分钟表达量级，底层保留秒以复算。固定舍入只用于展示，不在各行舍入后求和。多个片段的成员重叠先核销；可能并行而无去重依据的时间不形成完整总时长。

## 3. 自然试验的取样与负担

### 3.1 事先固定样本

对象为 WI550、发布后下一项自然发生且适用的外部 standard 工作、下一项适用的 lightweight 工作，不创建业务 WI 凑样本。外部两项须从目标形成开始保存；WI550 已发生的手工补记与新路径分开报告，不把后来导入冒充当时自动捕获。

校准使用 WI550 已保存的四个真实片段：原接手（Host 引用前缀 b78a07d0）、归属确认（e5877915）、重写与全过程计量要求（00e977ee）、计量设计委托（3bcccf8d）。完整引用从原生来源读回；短前缀仅为本表可读索引，不能作为机器身份。先按候选估计器保存这些片段的初估，再取得校准参考；这是历史校准集，不计入自然验证成绩。

冻结估计器和校准参数后开始自然验证：WI550 的首 2 个、下一项适用外部 standard 的首 4 个、下一项适用 lightweight 的首 2 个真实人类参与片段。选择该层的时间顺序前缀，不挑历史上容易记忆的片段。lightweight 的正常目标输入和验收输入即可形成两个片段，不为计量增加消息。三项工作的日历进度可以不同；不以等待时间代替人时。

选择只看所属工作、来源和顺序，不看估计好坏、参考值或产出是否成功。保存所有入选和不可观测原因，不事后替换失败/拒答片段。若工作已结束而未取得足够后续片段，证据不足，不为取样增造工作或消息。

8 个验证片段须至少涵盖共创/阅读判断、验收/协调、真实纠错/恢复三类用途。若固定集合未覆盖，则本次只能给已覆盖范围的结论，不能追加挑选好样本来宣布全范围通过。正式扩大证据范围需要先记新观察方案，保留原结果；不重开 WI。

历史 WI568/WI779 只检验已知产出识别反例，不能参加这组未知样本验证。隔离故障注入可以验证恢复机制，不能伪装成人类自然纠错时间。

### 3.2 人类核对

只在自然工作停顿点提交两次紧凑核对：校准批 4 项、验证批 8 项。批次汇齐前只保留来源与先验估计；参考回忆过宽或已无法回忆时据实判证据不足，不偷偷改用历史重构。每项包含可识别的事情、用途及材料，询问主动投入区间、未记入的工作和明显错归；不先展示估计答案。参考优先使用已经存在的真实计时，没有则用当事人即时回忆的区间，并明确是自报而非秒表真值。

不增加屏幕录制、键盘/鼠标监控、后台阅读跟踪、持续计时或每轮打卡。核对本身的阅读和回答负担也计入本 WI；不把两次核对排除在成本外。用户可以不答，未答记为证据不足，不推断认可。

负担上限：两批各不超过 2 分钟主动核对，总额最多 4 分钟；超过即停止核对并记负担门失败，不追加问卷。日常新增必须人工填写的步骤为 0。时间由当事人自报区间或已存在计时提供；上界不可确认时，不能宣称负担门通过。

该上限小于本试验所要辨认的 5 分钟负担量级；它不是“已经节省 5 分钟”的收益基线。核对时间、自动计量机器投入、人工恢复和保存失败另列，用真实基线判断收益是否抵消，不能只看低于上限。

## 4. 通过、失败与证据不足

以下条件同时成立才可把首版人时估计标为“在这组有界自然样本中可用”：

| 检查 | 预先固定门槛 | 判定依据 |
|---|---|---|
| 原生活动完整性 | 指定来源、截止内的应有事件集合与实收集合完全一致；重复原始用量、串 WI、伪造人审均为 0 | Host/渠道来源库存独立核对，不用估计器自己的输出当分母 |
| 可比参考 | 8 个验证片段均有有限参考区间；参考宽度不超过 `max(60 秒, 0.4r)` | 宽泛回忆无法用来验证精度；缺失不是 0，也不删除样本 |
| 个体误差 | 至少 7/8 个满足 `abs(m-r) <= max(60 秒, 0.30r)` | 与有限参考的中点偏差，不外推真实总体误差 |
| 区间覆盖与宽度 | 至少 7/8 个预测区间包含完整参考区间；每个预测区间宽度不超过 `max(120 秒, m)` | 防止靠无限宽区间取得覆盖 |
| 汇总偏差 | 同一不重叠集合 `abs(sum(m)-sum(r)) <= max(120 秒, 0.20sum(r))` | 2 分钟误差预算小于 5 分钟判别量级；相互抵消不能替代个体误差门 |
| 用途解释 | 8 个中至少 7 个主用途与核对相符；涉及纠错/恢复的片段不遗漏该用途 | 共创不直接标成浪费，多用途不重复计时间 |
| 未记录投入 | 同一有界样本内，明确漏记主动时间上界 / 全部参考主动时间下界 ≤ 10%；分母为 0 或漏记无界则证据不足 | 限定片段外的人生/工作不可推断；不能以此证明全生命周期无漏 |
| 核对负担 | 两批各 ≤ 2 分钟，总额 ≤ 4 分钟；日常强制人工步骤=0 | 按参考上界判断；未知不判通过 |
| 自动开销 | 新路径相对固定旧路径的额外标准机器估值 ≤ 5%，且无额外独立估计模型调用 | 同一已冻结输入、结果可比的成对执行；缺价/不可比则不足，不以 Token 总数代替金额 |

`r` 是参考中点，`m` 是校准后估计中点；恰好等于阈值判通过。尺度、误差线、入选顺序与样本集合在读取验证参考前固定。上述小样本只证明列明场景，没有统计总体保证。

自动开销比较使用固定候选之前的原生产算法和新算法，对同一脱敏输入集/模型分项/固定价格快照分别执行；对缺少旧语义能力的部分不捏造旧结果，单列新增语义记录开销及来源覆盖。无法形成可比金额时，该门不能通过。新增语义与已有阶段工作共用一次模型调用，其额外 Token 用固定提示及输出差分的独立成对实验估计，标为 estimated，不从生产整轮 Token 拍脑袋分摊。成对实验本身单列成本。

缺少样本、参考、时长或价格是 evidence_insufficient（证据不足），不是 pass。超过门槛为 fail。未支持用途不外推。失败后先复核错误原因，再按原停止条件缩范围或重新设计；保留已失败验证，不用调阈值覆盖旧结果。

## 5. 产出、质量、价值与一致性

- 在三个自然工作和历史反例中，独立核验人逐项核对目标、业务对象、版本、贡献、验收引用及缺项。已形成对象漏记/重复新增/版本串用为 0；一项根本不成立即该项验收失败，不按“多数正确”掩盖。
- 查询与 Stats 使用同一规范结果、时区、对象集合、知识水位和价格摘要；按类别/单位核对明细与汇总精确一致。已知子集与未知部分分列，不在缺项时声称完整。
- 正常路径、跨会话接续、重复提交、真实新增调用、进程中断后恢复和 lightweight→standard 分别验证；事实保存不产生执行权，未获工作区准入仍不得写源码。
- 人时估计、质量证据和收益不是一个分数。讨论收益前保存比较对象、同质量条件、实际基线、观察期和投入范围。没有可比基线，先交付可复算产出和投入，不声称减少负担或货币 ROI。
- 工程阶段完成只说明这套试验能够执行。自然试验结果、部署、消费者一致性与最终验收仍由后续图节点分别提供。
