状态：待实现的接口合同，不是可执行命令、已签发授权或迁移准入。

## 已核实的现有实现

- Harness `scl_human_decision.py` 与 Relay `src/scl-human-decision.ts` 当前只签发/验证 `action=reinit`。不得扩大既有回执的语义使其授权迁移，也不得改写原始字节或重签历史。
- Relay 经认证的人类输入包含渠道事件、发送者和原文摘要；Agent 转述、恢复摘要或工具输出不是人类来源。迁移授权只能由这一真实入口在明确批准后捕获，不能增加接受 Agent 自填事件/身份的通用 CLI signer。
- 当前 issuer 缺钥会自动创建，这是恢复验证路径不能调用 issuer 的原因。迁移入口必须使用已存在且验证过的 Host 信任根；缺失/损坏时拒绝，不自动补钥。
- `scl_authorization.py` 的已签署 recovery scope 绑定旧 `kernel_state_root`、resources 和 Git worktree/common-dir。`_reject_unadopted_scope`、`_record_decision_adoption` 与 `_validate_recovery_scope` 会检查这些绑定。单纯移动 key、设置新环境变量、复制 current index，不能证明新根上的原授权可用。
- 同 UID 的现有 HMAC 实现明确是 protocol boundary，不是对任意本机代码的密码学隔离。新的迁移入口不得宣称仅靠 HMAC 就杜绝伪造来源；执行环境、Host 捕获渠道和 A1 的实际隔离证据仍需成立。

## 最小实现要求

### 1. 明确的新迁移动作，而非复用 reinit

在现有 Host 人类来源捕获链上增加迁移专用动作及验证器；保持 v1 reinit wire、标识与签名解释完全不变。新的迁移动作必须避免与同一输入上的其他动作发生回执标识碰撞。

签署内容至少绑定：WI、执行主体、批准阶段、允许的具体操作、source/target exact roots、ledger repo/ref、对象清单摘要、受审执行器 revision/输入闭包、有效起止时间、当前授权版本/撤销状态。机器消费者从所执行操作判断所需阶段，不信任调用方将 cutover 标成 prepare。

A 阶段只允许已确认的只读盘点与隔离对象操作。C（停写/导出/导入）和 D（凭据/数据权威/运行切换）需各自真实人类批准；C 的回执不能自动授权 D。当前 user 的持续准备授权不能转成上述生产回执。

### 2. 真实来源和当前性

签发仅发生在认证 Host 输入处理链，并绑定用户实际批准的 exact plan/manifest；改变路径、版本、清单或阶段后必须失效。事件重投同内容返回同一原始回执；相同事件但不同范围必须拒绝。验证缺失来源、过期、尚未生效、撤销、被新版本替代均 fail closed。

当前性与撤销使用现有 Host 控制面的一处权威，不建立新的常驻授权服务或旁路数据库。签名正确不等于当前授权仍有效；每个不可逆步骤和重试必须重新读回。故障保留正常对话和授权请求，不能返回虚假持久化成功。

### 3. 原授权保全与受控映射

既有 source receipts/current index/adopted resources 原字节保全。以专用迁移记录关联旧根与新根、原授权与新的物理绑定；不能原地替换旧回执里的路径或把不相关 grant 当成原授权延续。

映射消费者需要核验同一 WI/owner/合法授权链、准确 source 与 destination registration、原事实 frontier 和迁移清单。路径映射不是扩大资源范围；不可让原先只授权某个工作树的决定覆盖整个 PULSE 或其他节点。旧授权的撤销/重叠规则在映射后仍有效。

### 4. 冻结、恢复与拒绝路径

切点与副本完整性验证不替代写入冻结。导出/附件/Host 回执与当前索引需对应同一个已证明的稳定切点。活动 OS 锁由流程退出/恢复重新建立，复制 `.lock` 字节不证明锁仍持有。迁移窗口已接纳请求、新 checkpoint 与 unknown effects 不得因回滚消失或重发。

## 必须通过的测试

- 经认证 Host 入口批准与签发的端到端合成测试；伪造/引用来源被拒。测试密钥与测试事件不作任何生产授权证据。
- reinit 回执、仅准备批准、过期/撤销/版本失配、错误 WI/主体/根/repo/ref/清单/工具版本，均不能执行生产操作。
- 缺钥不创建；旧签名 wire 不变；副本原文不变；同事件幂等与冲突拒绝。
- 原 scope 在新根只有经过合法映射才成立；错误映射、扩大权限、旧根复活、两边并发写均拒绝。
- 新事实产生后恢复兼容运行物不丢新事实；重试验证当前授权而非只复用旧成功状态。

## 当前边界
